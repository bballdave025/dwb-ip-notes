## Purpose

Learn probability, Markov chains, absorbing chains, exact stochastic calculations, Monte Carlo verification, and eventually Markov decision processes (MDPs) through questions arising from an actual Risk-like strategy game. The project should improve **the human player's reasoning**, not become an automated move oracle.

The game can also be an accessible educational example for friends or local upskilling collaborators, but that expansion is optional.

## Origin and inspirations

- Enjoyment of Risk-style games, including the earlier Warfish site and its now-unavailable *Binary Tree* game; a WarGear *Merge Sort* game is also of interest.
- A desire to revisit actual decisions and understand probabilistic and strategic tradeoffs.
- Preference for a lightweight, recreational activity that does not displace the user's RMMFB publication work or job search.

## Initial deliverable

A small reproducible event-history representation with clear evidence provenance. Preserve original visible history text (including dice notations) separately from later interpretations. The map states can be represented in a future territory/owner/army-count structure using stable territory IDs when identified.

A sensible data model has three layers:
1. **Raw evidence** — immutable screenshots and visible history lines with source references.
2. **Canonical history** — event IDs, actors, action types, source/destination territories, changes, known/unknown fields, and confidence/provenance.
3. **Analysis** — battle transition probabilities, expected losses, sensitivity analysis, comparisons of candidate actions, then optional strategic planning.

Prefer a source-neutral canonical format so a future WarGear API adapter can feed the same model. No API access or premium purchase is assumed.

## Potential technical concepts

- Exact enumeration of dice outcomes
- Absorbing Markov chains for localized combat
- Monte Carlo simulation as an independent numerical check
- Conditional expected values and sensitivity to risk preferences
- Markov decision processes, reward definitions, and Bellman equations
- Opponent-policy modeling and partial observability (later)

A Markov model is only valid when its chosen state contains adequate information for the transition probabilities. Full-board modeling and opponent behavior may demand richer state or approximations.
